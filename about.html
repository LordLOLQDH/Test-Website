ÜBER DAS PROJEKT

Eine Website nur für Tests.

Das KDS Test Lab ist eine kontrollierte Beispielumgebung. Hier können neue Banner-Versionen, Einbindungen, Layouts und Web-Komponenten ausprobiert werden, bevor sie auf echten Websites eingesetzt werden.

Wichtig

Das KDS Banner wird zentral über den offiziellen Embed-Schnipsel geladen. Dadurch bleibt diese Testseite möglichst nah an einer echten Kundenwebsite.
